การติดตั้งระบบอัปเดตอัตโนมัติวันละ 2 ครั้ง (06:00 & 18:00 น.)

ทำงานฟรี 100% บน GitHub Actions ไม่ต้องเปิดคอมพิวเตอร์ทิ้งไว้

ขั้นตอนที่ 1: สร้างไฟล์ Workflow บน GitHub

สร้างไฟล์ที่พาธ .github/workflows/update.yml โค้ดนี้จะสั่งรันอัตโนมัติที่เวลา 23:00 และ 11:00 UTC (ตรงกับ 06:00 น. และ 18:00 น. ประเทศไทย): 

name: TCAS Views Crawler (2x Daily)

on:
  schedule:
    # 06:00 และ 18:00 ICT (UTC 23:00 & 11:00)
    - cron: '0 23,11 * * *'
  workflow_dispatch: # กดรันแบบ Manual เมื่อต้องการได้ทันที

jobs:
  scrape-views:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Setup Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      
      - name: Run Scraper
        run: python updater.py

      - name: Commit and Push Updated Data
        run: |
          git config --global user.name "TCAS-View-Bot"
          git config --global user.email "bot@mytcas.local"
          git add data.json
          git commit -m "Auto-update TCAS views (2x Daily) [skip ci]" || echo "No changes"
          git push
ขั้นตอนที่ 2: สคริปต์ Python สำหรับกวาดข้อมูล (updater.py)

สร้างไฟล์ updater.py ไว้ที่โฟลเดอร์หลักของโปรเจกต์ สคริปต์นี้จะวิ่งไปดึงยอดวิวจริงจาก course.mytcas.com และเขียนลง data.json: 

import urllib.request
import re
import json
import time
from datetime import datetime

# รายชื่อรหัสหลักสูตรที่ต้องการติดตาม (เพิ่มได้ตามต้องการ)
PROGRAM_IDS = [
    "10010111110101A", "10010121110101A", "10020115110101A",
    "10020118110101A", "10030113110101A", "10040114110101A"
]

results = []
headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)'}

for pid in PROGRAM_IDS:
    url = f"https://course.mytcas.com/programs/{pid}"
    try:
        req = urllib.request.Request(url, headers=headers)
        with urllib.request.urlopen(req, timeout=10) as resp:
            html = resp.read().decode('utf-8')
            match = re.search(r"ยอดผู้เข้าชม\s*([\d,]+)\s*ครั้ง", html)
            views = int(match.group(1).replace(",", "")) if match else 0
            results.append({"id": pid, "views": views, "crawledAt": datetime.now().isoformat()})
            print(f"OK {pid}: {views} views")
    except Exception as e:
        print(f"Error {pid}: {e}")
    time.sleep(0.3)

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(results, f, ensure_ascii=False, indent=2)
